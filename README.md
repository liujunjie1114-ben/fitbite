# 食刻 FitBite

**吃得明白，练得更好。** 面向健身新手的中文饮食记录网页，手机、电脑均可使用。

输入「米饭150克，鸡胸肉200克，2个鸡蛋」，查看热量、蛋白质、碳水与脂肪，确认克重后记入当天饮食。

## 在线使用

- 网站：https://liujunjie1114-ben.github.io/fitbite/
- 源代码：https://github.com/liujunjie1114-ben/fitbite

## 首版功能

- 48 项常见食物参考资料，区分部分生熟状态；支持搜索、分类、自定义包装营养值。
- 文字份量解析：克、g、kg、公斤、斤、两、毫升及适用的个/杯/碗/片等；未知食物或不适用单位会提示，不会伪造数值。
- 估算草稿可修改克重、移除食物，点击确认才记账。
- 每日热量、三大营养素进度、早餐/午餐/晚餐/加餐记录、日期回看、删除撤销。
- 手动设置每日参考目标；初始 2000 kcal / 120 g 蛋白质 / 250 g 碳水 / 60 g 脂肪仅演示，不是根据身体情况计算的个性化建议。
- 饮水记录、浏览器本地保存、JSON 导出、经格式校验并二次确认的备份导入。
- **实验性拍照识别**：按需下载开源 Swin Food-101 模型，由 Transformers.js 在浏览器本机运行，不需要 API Key。输出前三候选，确认食物和克重后手动保存。只有有明确资料映射的类别可直接填入草稿，其他类别引导搜索或自定义食物。

## Windows 本地运行

安装 Node.js 20 或以上，在项目目录运行：

```powershell
npm start
```

打开 http://127.0.0.1:4173 。无构建步骤、无 npm 依赖安装。请通过 HTTP 打开，直接双击 HTML 的 file:// 模式无法正常加载 ES Modules。

```powershell
npm test
npm run check
```

## 拍照识别的实际限制

首次使用需要联网下载约 **93.3 MB** 量化模型和推理运行时，之后由浏览器缓存；网络需能访问 Hugging Face 与 jsDelivr。弱网、低内存手机或受限制网络可能无法加载，此时仍可使用文字记录。没有预下载模型的离线设备不能首次识别。

Food-101 是单张照片的常见菜品分类模型，无法可靠测量重量、识别所有中餐、拆解多道菜，非食物也可能产生候选。分类分数不是营养准确率。请自行确认实际食物，输入称量重量；加油、酱料与烹调差异需要额外记录。

## 隐私与数据

没有用户账户或服务端数据库。饮食、目标和饮水记录通过 `localStorage` 留在当前浏览器；不会跨设备同步，清理浏览器数据后可能丢失，请定期导出备份。照片在本机缩放后识别，不上传模型服务，不保存进日记或备份。下载字体和模型会产生到第三方 CDN 的普通网络请求。

备份包含饮食记录，分享前请自行检查。导入会替换当前浏览器数据，并先展示记录数量要求确认。

## GitHub Pages 部署

1. 将源代码推送至公共仓库 `main` 分支。
2. 仓库 **Settings → Pages → Deploy from a branch**，选择 `main` 和 `/ (root)`。
3. 等待 Pages 部署成功后打开仓库给出的网址。

所有站内资源采用相对路径，可部署在项目子路径。不需要服务端密钥或收费 API。

## 开源与定位

本项目独立实现，应用源代码为 MIT 许可。曾调研 NutriLens、NutriNutri，未复制其应用代码。照片分类使用的模型、运行时各自遵循其原有许可，详见 [SOURCES.md](./SOURCES.md)。内置数值是参考近似值，不是完整或经过逐条核验的临床营养数据库；复合餐食差异尤其明显。本工具用于一般饮食记录，不提供医疗诊断或疾病饮食处方。
