## 真实照片推理

通过页面上传一张公开披萨照片，运行随站点分发的模型和 ONNX Runtime Web，实际输出前三候选：

1. 披萨：约 83.6%
2. 千层面：约 13.5%
3. 法式洋葱汤：约 1.0%

选择「披萨」后进入可编辑的 120 克参考份量草稿，约 319 kcal，不会自动保存日记。

测试图片来源（仅用于本地 QA，图片未包含在源码仓库）：https://commons.wikimedia.org/wiki/File:Eq_it-na_pizza-margherita_sep2005_sml.jpg

这是一张图片的冒烟测试，不能推导整体精度、所有食物的表现或手机性能。模型类别分数不等于营养准确率，仍须人工确认食物和称量重量。

## 已知边界

本版没有账户、云同步或经过逐条 FDC ID 验证的完整营养库；内置条目为常见参考近似值。照片不测重量，不拆解多道菜，中餐覆盖有限。目标需要手动填写，默认数值不是个性化处方。数据保存在浏览器，应定期导出。
